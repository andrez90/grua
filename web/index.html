Control remoto por Bluetooth y USB

Desconectado
Tu navegador no soporta Web Bluetooth. Abre esta página con Google Chrome o Microsoft Edge (en computador o Android), y asegúrate de estar en una dirección https:// o http://localhost.
⚠️ Se perdió la señal con la grúa (sin respuesta hace más de 7 segundos). Verifica que el ESP32 esté encendido y dentro de rango.

Conexión automática

Antes de empezar

📌 Haz clic en «USB» o «Bluetooth» para conectar.
  1. Si tienes el Arduino o ESP32 conectado por USB, la app lo detectará automáticamente.
  2. Si usas Bluetooth, pulsa Bluetooth y elige el equipo en la lista.
  3. Cuando el punto de estado se ponga verde, ya puedes mover los servos.

Control por arrastre 🖱️

Arrastra el ratón en el área para mover la base y el hombro. Rueda del ratón para el codo.

Base: 90° · Hombro: 140° · Codo: 90°

Mando de control

Mantén presionado un botón para mover, como en una máquina de peluches.

🕹️
Brazo (codo)
Garra

También con el teclado: ↑↓←→ para mover, Q/E para recoger/extender el codo, Espacio para abrir/cerrar la garra.

Ajuste fino (sliders)

Movimientos grabados

Graba una secuencia de movimientos y reprodúcela luego con un clic. Cada slot guarda un movimiento distinto (hasta 6).
